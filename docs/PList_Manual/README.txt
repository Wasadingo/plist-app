CARPETA DE DOCUMENTACION PLIST

Contenido:

- Manual_PList_Proyecto.docx: manual editable para Word.
- Manual_PList_Proyecto.pdf: copia en PDF para consultar o presentar.
- crear_manual.py: archivo fuente para regenerar el manual después de cambios importantes.

El manual no incluye contraseñas, claves service_role, claves privadas VAPID ni API keys secretas.
Esas credenciales deben permanecer en Supabase o en un gestor de contraseñas.

Cuando se modifique una función importante de PList, hay que actualizar el manual, volver a generar el DOCX y volver a convertirlo a PDF.
